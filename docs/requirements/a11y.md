# A11Y requirements

Accessibility.

### REQ-A11Y-001 - Images have alt text

- Status: implemented
- Priority: should
- Source: spec / TODO
- Description: Meaningful images have descriptive alt text.
- Acceptance:
  - Given a page with product or content images
  - When it renders
  - Then each meaningful image has non-empty, descriptive alt text
- Test: none (not functional behaviour; outside the e2e scope)

### REQ-A11Y-002 - Interactive controls are keyboard accessible

- Status: draft
- Priority: should
- Source: spec / TODO
- Description: Interactive controls are focusable and operable by keyboard with visible focus states.
- Acceptance:
  - Given an interactive control (button, link, picker, accordion)
  - When navigating with the keyboard
  - Then it is reachable via Tab, operable via Enter/Space, and shows a visible focus state
- Test: tests/e2e/a11y.spec.ts > REQ-A11Y-002 (todo)
